# 刘桂锋个人履历与学术主页

这是一个适合 GitHub Pages 的纯静态个人主页，不需要服务器或数据库。

## 当前页面结构

- 个人简介与核心数据
- 临床、科研与教学方向
- 影响因子排名前10的代表性论文及发表年度影响因子
- 教学与人才培养
- 学术与行业服务
- 邮箱联系方式

## 后续补充素材

建议按下面的顺序逐步提供，信息不必一次发完：

1. 新增代表性论文及对应年度影响因子
2. 需要公开展示的科研项目、专利或著作
3. 新增教学成果与学术任职
4. ORCID、Google Scholar、机构主页等公开链接

## GitHub Pages 发布方式

内容确认后，将这些文件上传到 GitHub 仓库，在仓库的 **Settings → Pages** 中选择从默认分支根目录发布，即可获得公开链接。

页面支持手机、平板和电脑浏览，也可使用页面顶部的“打印 / 保存 PDF”按钮导出纸质版。
