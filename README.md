# 刘桂锋个人履历与学术主页

这是一个适合 GitHub Pages 的纯静态个人主页，不需要服务器或数据库。

## 当前页面结构

- 个人简介与核心数据
- 临床、科研与教学方向
- 职业与教育经历
- 论文、项目、专利等科研成果
- 教学与学术服务
- 荣誉与专业资质
- 联系方式与外部学术主页

## 后续补充素材

建议按下面的顺序逐步提供，信息不必一次发完：

1. 姓名中英文写法、现任职务、所在机构、城市
2. 个人照片（建议清晰竖版半身照）
3. 80–120 字个人简介
4. 临床专长、研究方向、教学方向
5. 教育经历和工作经历（起止年份、机构、职务）
6. 代表性论文、科研项目、专利或著作
7. 教学经历、学术任职与社会服务
8. 荣誉奖项、人才称号和专业资质
9. 公开邮箱及 ORCID、Google Scholar、机构主页等链接

## GitHub Pages 发布方式

内容确认后，将这些文件上传到 GitHub 仓库，在仓库的 **Settings → Pages** 中选择从默认分支根目录发布，即可获得公开链接。

页面支持手机、平板和电脑浏览，也可使用页面顶部的“打印 / 保存 PDF”按钮导出纸质版。
